# coletor_produtos_flask

Aplicação web desenvolvida com Python e Flask para coleta, filtragem e análise de  produtos utilizando Web Scraping com Requests e BeautifulSoup.

Etapa 1 - Preparação do ambiente

Ferramentas necessárias :

Python.
Visual Studio Code.
Flask.
Requests.
BeautifulSoup4.

1.2 Criamos a pasta do projeto "coletor_produtos_flask" :

1.3 Comandos :

Esse comando verifica se pýthon está instalado e dispoível no terminal.
Executamos todos os comandos a seguir no terminal do Git-Bash. 
python --version

1.4 Criamos o ambiente virtual :
python -m venv venv

O ambiente virtual permite instalar as bibliotecas do projeto sem interferir nas demais instalações do Python.

1.5 Ativamos o ambiente virtual :
source venv/Scripts/activate

Se estiver tudo certo o comando acima retorna.
(venv) 

1.6 Instalamos as bibliotecas :
pip install requests beautfulsoup4

1.7 Conferir a instalção :
Essas são as três bibliotecas principais da atividade.

pip list

ºFlask
ºrequests
ºbeautifulsoup4

1.8 Teste final da etapa

Implementamos o arquivo teste.py para verificar se todas as biblioteca estão configuradas corretamente e se ambiente virtual está funcionando adequadamente.

python teste.py

Se aparecer a mensagem : (venv)

Está tudo funcionando perfeitamente ! 

RESUMO DA FINALIDADE DO CÓDIGO

O arquivo teste.py realiza uma verificação básica das dependêcias do projeto, confirmando se as bibliotecas Flask, Requests e BeautifulSoup estão instaladas e podem ser importadas corretamente no ambiente virtual.
